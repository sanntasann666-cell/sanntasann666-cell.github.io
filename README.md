# SANTA 手取り計算

メルカリ・ラクマ・Yahoo!フリマ・ヤフオク・BOOTH・BASE・minne・Creema の販売手数料と手取りを、ブラウザだけで比べる静的ツール。

- 登録不要、無料、広告なし（アフィリエイトは未接続）
- 計算は端末の中だけ。入力値をサーバーに送らない
- 料率の確認日: 2026-11-19（JST）。出典はページ下部と `js/fees.js`
- オフラインで動く（`index.html` を直接開いてよい）

このリポジトリだけで完結する。計算にネット接続やアカウントは不要。

## 動かし方

1. `index.html` をブラウザで開く（ビルド済みの `js/bundle.js` を読むので、ローカルファイルでも動く）
2. 販売価格などを入れると、比較表が更新される

開発時（このリポジトリのルートで）:

```bash
npm test          # 手数料テスト 16件 + bundle 再生成
# または
node --test tests/test_fees.mjs
node scripts/build.mjs
```

`js/fees.js` を直したら、必ず `npm test` を通す。`js/bundle.js` は生成物なので手で編集しない。

## できること

- 8サービスの手数料と手取りを同じ条件で比較
- 希望手取りから、必要な販売価格を逆算
- 価格帯の早見表
- 既存の SANTA ショップ無料シートへの案内（有料商品は需要ゲートを満たすまで出さない）
